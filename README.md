One line about a cat: I taught her to come when called, and now she comes, stares at me, and walks away, just to prove she could.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
